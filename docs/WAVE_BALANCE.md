# 포위 웨이브와 돌파 무기 — 로컬 적용

## v1.0.1 배포 이후: 경계와 겨울 압박 수정

아래 항목이 이전 수치보다 우선한다. 아직 별도 배포하지 않은 로컬 변경이다.

- 일반 몹 생성은 장르 관례대로 맵 안 · 카메라 밖을 유지한다. 벽 쪽이 조금 안전한 것은 인정하고, 그 보정은 아래 웨이브가 담당한다. 이동 경계 제한도 일반 몹·버섯·보스는 유지한다.
- 웨이브 몹(포위·멧돼지 포위·박쥐)만 맵 바깥에서 생성되어 경계를 넘어 들어온다. 포위는 가장자리에서도 완전한 원을 유지하고 박쥐 줄도 맵 바깥 부분을 삭제하지 않는다. 바깥에서 생성된 박쥐는 즉시 제거하지 않고 기존 수명으로 퇴장한다.
- 버섯 사수는 웨이브에서도 맵 안 좌표에만 배치한다(맵 안 비약점 포인트 4개당 1마리). 도달 불가 위치에서 저격하는 상황을 막기 위해서다.
- 밀쳐내기는 경계 밖 120px까지만 허용한다. 화면 밖 이탈 판정에 걸려 몹이 증발하지 않게 하기 위한 상한이다. 맵 밖에서 죽은 몹의 경험치·특별 도토리는 경계 안쪽 40px 지점으로 옮겨 떨어진다.
- 맵 가장자리의 약한 포위 구간은 안쪽을 향하도록 배치한다. 예고·플레이어 바로 위 생성 방지·전체 개체수 상한은 유지한다.
- 일반 멧돼지 상한은 가을 10·12·14, 겨울 16·18·20(1·2·3년차)으로 늘렸다. 헬은 3분부터 10에 5분당 1씩 더하며 최대 24다.
- 겨울 순환은 멧돼지 포위 → 박쥐 → 버섯 → 박쥐다. 멧돼지 포위는 약한 뱀 구간 외에 멧돼지를 촘촘히 섞으며, 생성 시 일반 멧돼지 상한보다 최대 12마리 추가 허용한다. 기존 멧돼지도 합산하고 전체 몹 상한을 넘지 않는다.
- 포위형 웨이브 몹(포위·멧돼지 포위·버섯 포위)은 24초 제한을 없애고 조여든 뒤 일반 몹으로 남는다. 처치하면 경험치를 주므로 도망 대신 돌파가 이득이다. 총량은 기존 개체수 상한이 그대로 제한한다. 박쥐 횡단은 10초 후 보상 없이 퇴장하는 기존 규칙을 유지한다. 사수 버섯은 40초 공성 자세가 끝나면 사수 고정을 풀고 추격한다.
- 회귀 검증: 네 가장자리에서 일반 몹 맵 안·화면 밖 생성, 웨이브 몹의 경계 진입과 버섯 경계 유지, 바깥 박쥐 진입, 밀쳐내기 상한, 맵 밖 처치 보상 위치, 모서리에서도 완전한 겨울 포위와 멧돼지 예산. 테스트 123개 통과. 실전 난이도는 추가 플레이 확인이 필요하다.

## 보스 장기전 압박

보스 등장 후 2/3/4분에 특별 웨이브 간격을 기존의 72%/50%/36%로 줄인다(최소 18초). 1년차 겨울 기준 68→49→34→24.5초이며 예고 1.25초는 별도다. 단계 상승 시 알림과 함께 다음 대기를 최대 8초로 줄인다. 일반 몹 보충 완화 시간은 30→24→18→12초로 줄고, 3분부터 1·2년차에서도 버섯과 박쥐 복합 웨이브가 가능하다. 개체수 상한과 돌파 구간, 예고는 유지한다. 보스 체력과 공격력은 변경하지 않는다.

헬은 가장 오래 살아 있는 보스의 등장 시각을 기준으로 계산한다. 보스 처치 시 남은 보스에 맞춰 단계가 내려가고, 모두 처치하면 해제된다. 일시정지와 레벨업 중에는 경과하지 않는다. 최대 단계는 3이다. 이 변경까지 테스트 115개와 빌드를 통과했다.

## 적용한 전투 흐름

- 정규 스토리 봄 2분부터 포위 웨이브. 1.25초 동안 실제 등장 위치를 표시한다. 초반 첫 2분의 일반 스폰은 유지한다.
- 포위선은 반경 약 310~356에 맞춰 약 47~54마리로 배치하며, 연속한 약 20% 구간의 뱀은 기본 체력의 55%다. 맵 경계에서는 원을 잘라 배치하므로 수가 줄어든다. 예고에서 연두색으로 표시한다. 빈 통로 대신 처치 가능한 구간이다.
- 여름 이후 포위 → 박쥐 → 버섯 → 박쥐 순환. 봄에는 포위만 나온다.
- 박쥐는 1년차 2방향, 2년차 3방향, 3년차와 헬 4방향 횡단. 방향마다 15~17마리, 줄 길이 420~480. 일반 박쥐보다 체력 25% 증가, 웨이브 비행 속도는 계절별 280~325. 진행 방향에 수직인 배치에서 예고 종료 0.9초 뒤 예상 위치를 가로지른다.
- 버섯은 포위선의 고정 사수. 기존 버섯 개체수 제한 및 투사체 상한을 지킨다. 3년차와 헬의 버섯 포위에는 박쥐 횡단도 섞인다.
- 포위 몹은 포위 중심으로 접근한 후 추격한다. 24초 후 사라지며 경험치는 처치 시에만 나온다. 박쥐는 10초 후 퇴장한다.
- 웨이브 출현 뒤 30초간 일반 몹 보충 간격을 1.7배로 늘리고 추가 정예를 보류한다. 포위의 최대 24초 이후 약 6초가 회수 여유다.
- 다음 예고까지 68초를 기준으로 연차당 8초, 계절당 4초 단축한다. 헬은 연차 난이도 3 적용. 보스가 살아 있으면 12초 더 여유를 준다.
- 개체수 상한을 넘지 않는다. 예고 중 웨이브용 자리를 예약한다. 꽉 찬 경우 화면 밖 일반 몹만 회수하고, 여전히 공간이 없으면 3초 뒤 재시도한다. 화면 안 적·정예·보스를 회수하지 않는다.
- 맵 가장자리에서는 플레이어 중심 원을 월드 경계에서 잘라 배치하고 경계와의 교점을 채운다. 예고 지점에 플레이어가 진입했다면 65거리 안에서는 생성하지 않는다.

- 새총·채찍·부메랑: 이동 방향 앞쪽의 적을 우선하는 거리 가중 조준. 아주 가까운 뒤쪽 위협도 선택할 수 있고, 정지 시 기존 최근접 조준이다.

## 추천 조합과 성장 우선순위

균형 돌파: 새총 / 채찍 / 벌떼 / 번개 / 눈송이 / 부적.

새총 3~4레벨로 먼저 정면 화력을 확보하고, 채찍의 관통 길이를 올린 뒤 벌떼로 탱커를 보완한다. 번개는 약한 무리 제거, 눈송이는 돌파에 필요한 시간을 확보한다. 패시브는 공격력·공격속도를 우선하고 이후 체력 또는 이동속도를 보완한다. 여섯 무기를 모두 낮은 레벨로 넓히기보다 핵심 공격을 먼저 강화하는 선택이다.

공격적인 돌파: 새총 / 부메랑 / 벌떼 / 당구 / 꼬리 / 부적. 왕복 관통과 밀쳐내기로 구간을 열지만 눈송이 감속이 없어 더 적극적인 위치 선정이 필요하다.

거점형: 새총 / 비축고 / 불씨 / 번개 / 눈송이 / 부적. 비축고가 있는 구역 근처에서 싸우되 포위 예고가 나오면 약한 구간으로 이동한다. 계속 같은 자리에 머무르는 조합으로 보장하지 않는다.

추천은 역할에 근거한 초기 제안이다. 전체 런의 동일 성장 투자량·동일 시드 비교를 통과한 최적 조합이라는 뜻은 아니다.

## 40레벨 클리어 해석

현재 코드에는 클리어 레벨 목표나 40레벨 제한이 없다. 요구 경험치는 `round(7 + level*3 + level^1.34*1.4)`이며 레벨 40까지 누적 5,872, 50까지 9,545, 60까지 14,223이다.

40레벨이면 레벨업 선택 39회다. 기본 새총 외 무기 획득에도 선택을 사용하며 패시브와 분배하므로, 모든 무기·패시브 완성은 기대할 수 없다. 핵심 무기 몇 개와 보조 효과를 완성하는 정도의 클리어는 설계상 가능하다. 기존에 40을 의도적으로 목표로 맞췄다고 볼 근거는 없다.

웨이브로 경험치 공급 기회가 늘었지만 처치하지 않고 만료된 적은 경험치를 주지 않는다. 따라서 요구량까지 낮추지 않고 유지한다. 다음 플레이 검증에서 최종 레벨뿐 아니라 핵심 무기 완성 시점, 피격, 포위 탈출 시간, 보스 처치 시간을 함께 비교한다. 목표 레벨을 보장하거나 추가 경험치 총량을 단정하지 않는다.

## 도주 위주 클리어 피드백 반영

멧돼지 체력과 전체 스폰 비율은 낮추지 않았다. 종류별 상한은 1년차 가을 6/겨울 8, 2년차 8/10, 3년차 10/12이다. 헬은 3분부터 8마리에서 5분마다 1마리씩 증가하여 최대 18이다. 일반·웨이브·정예 생성에 적용한다. 정예 멧돼지는 동시에 한 마리만 생성하고 추가 정예는 여우로 대체한다. 상한에 도달하면 다른 종류를 생성해 전체 압박은 유지한다. 이미 살아 있는 멧돼지를 즉시 제거하지는 않는다.

포위 중심은 예고 시작 시 플레이어 위치로 고정한다. 반경은 최대 이동속도와 1.25초 예고시간을 고려해 생성 전 이탈을 막는다. 박쥐는 현재 이동속도와 방향으로 예고 및 비행 시간 뒤의 위치를 한 번 예측하고 고정한다. 방향 전환으로 대응할 수 있다. 8방향 직진 시 박쥐 접촉, 방향 반전 시 회피를 게임 코드로 확인했다. 맵 중앙·모서리·가장자리에서 최대 속도 16방향 이동 시 포위 생성 순간 안쪽에 남는지도 확인했다. 실전 승률 비교는 아직 필요하다.

박쥐 줄 확장: 기존 9~11마리(240~300)에서 15~17마리(420~480)로 확대했다. 속도·주기는 유지한다. 버섯 복합 웨이브에서 개체수 예산이 부족하면 각 방향의 바깥쪽 박쥐를 대칭으로 줄여 중앙 교차 경로를 유지한다.

## 접촉 피해 제한

일반 몹 접촉은 같은 개체당 0.6초 재타격 제한, 실제 피격 후 전체 보호 0.15초를 적용한다. 최근 0.5초의 접촉 피해 합계를 고정 50으로 제한하며, 남은 허용량만큼 마지막 피해를 적용한다. 최대 체력에 비례하지 않는다. 보스 접촉·패턴·투사체는 이 상한에서 제외하고 기존 피격 보호 0.85초를 유지한다. 부적은 기존 0.5~0.7초 무적을 유지하고 막은 피해는 접촉 누적량에 포함하지 않는다. 1년차 20분 멧돼지 두 마리의 약 50.22 피해는 상한 50까지 적용된다.
