# 다음 작품 구상 · 다람이의 마법학교

## 확정된 연결

이번 작품은 부모님과 재회하고 “이제 알려줄 때가 왔구나. 너는 마법사란다, 다람아.”라는 해리 포터 패러디 대사로 끝난다. 후속작은 호그와트와 관련된 마법학교 이야기로 구상한다. **디펜스 장르가 현재 후보이며, 제작이나 세부 규칙이 확정된 것은 아니다.**

부모님은 마법학교를 지키러 떠났다가 돌아온 마법사들이다. 학교를 지킨 뒤 서리로 막힌 귀환로를 찾고 있었으며, 다람이가 숲의 서리 심장을 깨뜨려 길을 열었다. 단순히 혈통 덕에 이긴 것으로 바꾸지 않는다. 올빼미의 편지는 후속작으로 넘어갈 시각적 단서다.

## 제안하는 플레이 방향

- 학생이 된 다람이가 학교의 온실·기숙사·금지된 숲 가장자리를 지키는 웨이브 디펜스.
- 직접 움직이는 다람이와 설치형 마법 방어물을 함께 운용하는 액션 디펜스를 우선 후보로 둔다.
- 수업에서 주문을 익히고, 낮에는 배치를 준비하며 밤에는 몰려오는 적을 막는다.
- 도토리 비축고 → 마법 도토리 포탑, 버섯 포자 → 감속 지대, 나무껍질 부적 → 방어 결계로 기존 무기를 계승할 수 있다.
- 마법 지팡이는 작은 나뭇가지, 모자는 꼬리 때문에 자꾸 벗겨지는 등 다람이의 생김새와 행동으로 패러디를 만든다.
- 보호 대상은 학생·온실의 씨앗·학교의 결계 같은 구체적인 대상으로 잡는다. 부모님이 하던 ‘다른 생명을 지키는 일’을 다람이가 이어받는다.

## 다음 제작 전에 결정할 것

거점 설치 중심인지 직접 조작 중심인지, 스테이지 길이, 실패 조건, 호그와트와의 구체적인 연결 범위, 성장 초기화 단위는 후속작 제작 시 정한다. 지금은 현재 작품의 엔딩과 다음 장르의 연결만 반영한다.
