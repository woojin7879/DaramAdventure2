# 무기·도토리 선택안과 아트 제작 기준

작성일: 2026-09-11 · 상태: 원작 속성 조합 채택. 특별 도토리 효과는 후보.

## 1. 무기 선택 원칙

이름과 색만 바꾸기보다 적을 맞히는 방식과 플레이어의 이동이 달라지는 무기를 고른다. 아래 19종은 후보 기록이며 원작 속성 8종과 부적·포자·벌떼·비축고, 총 12종을 채택했다. 동시 장착은 시작 무기를 포함해 **최대 6칸으로 확정**했다. 채택 무기의 최대 레벨·단계별 효과·공격 판정은 [WEAPON_PROGRESSION.md](WEAPON_PROGRESSION.md)에 정했다. 아래 표는 후보 요약이며 채택 무기의 구현은 상세 성장표를 우선한다. 진화는 후속 제안이다.

| 번호 | 무기 | 자동 공격 방식 | 잘하는 것 / 약점 | 강화 시 변화 |
| --- | --- | --- | --- | --- |
| W01 | 도토리 새총 | 가장 가까운 적에게 도토리 연사 | 안정적인 단일 공격 / 포위에 약함 | 2연사 → 관통 → 부채꼴 발사 |
| W02 | 밤송이 폭탄 | 적 무리에 던져 지연 폭발 | 밀집 적 처리 / 빠른 적이 벗어남 | 파편 → 작은 폭탄 분열 |
| W03 | 솔방울 산탄 | 이동 방향으로 짧은 산탄 발사, 정지 시 마지막 방향 유지 | 전방 길 뚫기 / 후방 취약 | 탄수 증가 → 밀쳐내기 |
| W04 | 단풍잎 부메랑 | 가까운 적 방향으로 날아갔다 돌아옴 | 왕복 관통 / 돌아오는 경로를 맞춰야 함 | 잎 수 증가 → 넓은 곡선 궤도 |
| W05 | 꼬리 휩쓸기 | 주기적으로 가장 가까운 적 방향을 넓게 휘두름 | 근접 탈출 / 원거리 대응 불가 | 넉백 → 양방향 휩쓸기 |
| W06 | 조약돌 궤도 | 돌이 다람이 주변을 일정 반경으로 회전 | 근접 방어 / 궤도 안쪽 사각 | 돌 수 증가 → 안팎 이중 궤도 |
| W07 | 도토리 팽이 | 근처에 팽이를 발사, 지면을 지그재그로 이동 | 넓은 지역 지속 타격 / 표적 집중 어려움 | 지속 시간 → 팽이 분열 |
| W08 | 덩굴 채찍 | 근처 적 방향으로 긴 직선 타격 | 줄지은 적 관통 / 측면에 약함 | 길이 → 교차 채찍 |
| W09 | 버섯 포자 | 일정 거리 이동할 때 뒤에 포자 구름 생성 | 추격 적 처리 / 제자리에서 비효율 | 구름 지속 → 감속 |
| W10 | 뿌리 덫 | 근처 밀집 지점에 예고 후 뿌리 솟음 | 이동 제어 / 직접 피해 낮음 | 범위 → 짧은 속박, 보스는 약한 감속 |
| W11 | 벌떼 친구 | 벌들이 주기적으로 가까운 적에게 출격 후 귀환 | 이동 중 추적 공격 / 귀환 중 공백 | 벌 수 → 연속 표적 공격 |
| W12 | 반딧불 등불 | 주변을 돌던 빛이 적에게 돌진한 뒤 복귀 | 방어·추격 혼합 / 두 역할 사이 공백 | 빛 수 → 복귀 경로 관통 |

| W14 | 가지 번개 | 가까운 적에게 번개, 이웃 적으로 연쇄 | 모여 있는 적 / 고립된 적에 효율 낮음 | 연쇄 횟수 → 갈라지는 낙뢰 |
| W15 | 눈송이 고리 | 주기적으로 바깥으로 퍼지는 얼음 고리 | 포위 완화·감속 / 긴 공격 간격 | 고리 크기 → 추가 고리 |
| W16 | 바람개비 씨앗 | 다람이 주위에서 나선형으로 퍼지는 씨앗 | 전방위 견제 / 가까운 단일 적 집중 어려움 | 씨앗 수 → 회전 방향 교대 |
| W17 | 도토리 당구 | 적에게 맞을 때 주변 다른 적으로 튕김 | 밀집 적 연속 타격 / 주변 적 없으면 종료 | 반사 횟수 → 마지막 충돌 폭발 |
| W18 | 겨울 비축고 | 주기적으로 발밑에 도토리 포탑 설치, 가까운 적 자동 사격 | 거점을 돌며 싸우기 / 멀리 이동하면 지원 상실 | 설치 수 → 교차 사격 |
| W19 | 나무껍질 부적 | 보호 횟수를 충전해 피격 차단 | 생존 안정성 / 직접 공격 없음 | 보호 상한·재충전·방어 후 무적 강화 |

모든 무기는 자동 발동하고 경험치 점이나 특별 도토리를 탄약으로 소비하지 않는다. 설치물·동료·지속 구름은 생성 수와 수명을 제한한다.

### 선택 조합 예시

- **다람이와 숲 중심:** W01 새총, W02 밤송이, W04 단풍잎, W05 꼬리, W09 포자, W11 벌떼, W16 씨앗, W18 비축고.
- **원작 속성 계승:** W01 새총, W05 꼬리, W06 조약돌, W08 덩굴, W13 불씨, W14 번개, W15 눈송이, W17 당구.
- **이동과 궤도 중심:** W03 산탄, W04 부메랑, W06 조약돌, W07 팽이, W09 포자, W12 반딧불, W16 씨앗, W18 비축고.

**채택: 원작 속성 계승 조합.** W01·W05·W06·W08·W13·W14·W15·W17과 추가 채택한 W19 부적·W09 포자·W11 벌떼·W18 비축고를 최초 무기 목록으로 둔다. 나머지는 후속 후보로 보관한다. 원작에서 확인한 불·번개·돌을 중심으로, 다람이의 꼬리와 숲·겨울 소재를 확장한 조합이다. 모든 무기가 원작에 있던 것은 아니다.

## 2. 경험치 점과 특별 도토리

**일반 경험치 = 단순한 작은 점 / 특별 보상 = 도토리**로 확정했다. 일반 점은 가까이 가면 흡수되어 경험치 바를 채우며 기본 경험치 시스템을 따른다. 큰 경험치도 큰 점 또는 점 묶음으로 표현하고 일반 도토리 등급 체계는 사용하지 않는다.

특별 도토리는 일반 점보다 큰 실루엣과 효과 표식으로 구분한다. 공격용 도토리는 움직이는 궤적과 별도 외곽선으로 보상과 구분한다. 경험치 점을 합칠 때 총 경험치를 보존하고 특별 도토리는 별도로 유지한다.

아래 X01~X06은 특별 도토리 효과 후보이며 아직 채택하지 않았다. X07~X10은 이전 아이디어 기록으로 현재 구현 범위에서 보류한다.

### 특수 도토리 후보

| 번호 | 이름 | 획득 효과 | 플레이 변화 / 유의점 |
| --- | --- | --- | --- |
| X01 | 자석 도토리 | 경험치 + 주변 넓은 범위의 경험치 점 흡수 | 포위 속 회수 기회. 화면 전체 회수와 범위형 중 범위형부터 제안 |
| X02 | 쌍둥이 도토리 | 경험치 + 짧은 시간 기본 무기 추가 발사 | 수집이 공격 기회로 연결. 특수 공격은 추가 특수 드롭을 만들지 않음 |
| X03 | 싹튼 도토리 | 경험치 + 획득 위치에 잠시 치유 새싹 생성 | 도망갈지 회복 지점으로 돌아올지 선택. 회복 총량 제한 |
| X04 | 계절 도토리 | 경험치 + 현재 계절의 짧은 버프 | 봄 회복 / 여름 공격 가속 / 가을 흡수 범위 / 겨울 보호막 |
| X05 | 무지개 도토리 | 경험치 + 보유 무기 하나를 잠시 과충전 | 미완성 빌드에서도 강력한 순간. 영구 레벨·레벨업 후보에는 영향 없음 |
| X06 | 알찬 도토리 | 일반보다 많은 경험치, 엘리트가 확정 드롭 | 위험한 적을 잡고 보상을 회수하는 목표. 특수 시스템 없이 시작하기 쉬움 |

### 수집 방식 자체를 바꾸는 후보

| 번호 | 이름 | 규칙 | 장점 / 비용 |
| --- | --- | --- | --- |
| X07 | 볼주머니 | 경험치는 즉시 획득하고, 일정 개수 수집 시 잠깐 볼이 빵빵해지며 다음 기본 공격 강화 | 다람이만의 귀여운 피드백 / UI와 캐릭터 추가 프레임 필요 |
| X08 | 도토리 숙성 | 바닥에 오래 남은 일반 도토리가 한 번 숙성해 소량의 추가 경험치 제공 | 되돌아오는 경로 선택 / 기다리기가 정답이 되지 않도록 보너스 제한 |
| X09 | 도토리 저장 둥지 | 경험치는 즉시 획득하고 별도 비축 게이지 누적, 필드 둥지 방문 시 소진하며 회복 | 숲을 순환하는 이유 / 방문 강요와 캠핑 위험 |
| X10 | 수확 연속 보너스 | 짧은 시간 연속 수집하면 작은 흡수 범위 보너스, 최대 중첩 제한 | 이동 리듬 강화 / 연속 수집 실패로 기존 경험치나 보상을 잃지 않음 |

현재 검토 우선순위는 X01 자석, X04 계절, X06 알찬 도토리다. X06은 엘리트 특별 보상이므로 도토리 형태를 사용한다. 구체적인 효과·드롭 비율은 추후 확정한다. X07 볼주머니, X08 숙성, X09 저장 둥지, X10 연속 수확은 일반 도토리 전제의 이전 후보이며 현재 채택하지 않는다.

### 채택 시 공통 규칙

- 경험치는 획득 즉시 처리하고 연출이 레벨업을 지연하지 않게 한다.
- 같은 버프는 수치 무한 중첩 대신 지속 시간 갱신을 기본으로 한다. 정지 중에는 버프 시간도 정지한다.
- 특별 도토리는 계절이 바뀌어도 바닥의 기존 위치에 남는다. 직접 획득할 때 효과를 적용하고 진행 중 버프 시간도 유지한다.
- 스토리 단서는 드롭 운에 의존하지 않는다. 특별 도토리의 전투 효과와 이야기 해금을 분리한다.

## 3. 다람이 신규 아트 제작 기준

확정 방향: **에셋은 게임에 맞춰 새로 제작하고, 원작 다람이의 생김새 정체성을 유지한다.** 첫 초안용 신규 이미지를 생성했고 [ASSETS.md](ASSETS.md)에 기록했다.

### 유지할 외형

- 따뜻한 갈색 몸통과 밝은 크림색 얼굴·배의 대비.
- 몸 뒤로 크게 올라오고 말린 형태가 읽히는 풍성한 꼬리.
- 작은 귀, 짧은 팔다리, 원작과 이어지는 얼굴·몸·꼬리의 비율.
- 작게 표시해도 같은 다람이로 보이는 옆모습 실루엣.

색상 코드나 정확한 비율은 원작의 여러 자세를 비교한 뒤 캐릭터 기준표로 고정한다. 장비와 효과가 얼굴·꼬리를 덮거나, 외형이 일반적인 다른 다람쥐 캐릭터로 바뀌지 않게 한다.

### 새 게임에 맞춰 바꿀 부분

- 평면 필드에서 발 위치가 읽히는 시점과 그림자.
- 대기·걷기·피격·사망 동작. 활공·대시는 사용하지 않는다.
- 무기별 명확한 궤적과 타격 효과. 꼬리 공격에는 몸과 꼬리의 움직임을 연결한다.
- 적, 배경, 도토리, UI 아이콘의 픽셀 크기·외곽선·광원 통일.

### 제작 순서

1. 원작 대기·걷기·피격 이미지를 함께 보고 정체성 기준을 고정한다.
2. 같은 다람이의 표현만 달리한 시안 2~3개를 만든다. 정체성을 유지하는 선명한 픽셀, 조금 더 세밀한 픽셀 등의 표현 차이를 비교한다.
3. 원작과 시안을 나란히 놓고, 실제 플레이 크기로 축소해 얼굴과 꼬리를 확인한다.
4. 선택한 디자인으로 투명 배경 스프라이트를 제작한다. 프레임 크기·피벗·팔레트를 맞추고 애니메이션에서 형태가 흔들리지 않는지 확인한다.
5. 플레이어를 기준으로 적·경험치·무기·필드를 제작하고 실제 전투 화면에서 가독성을 검증한다.

## 4. 선택 기록

- 무기: 원작 속성 계승 W01·W05·W06·W08·W13·W14·W15·W17 + W19 부적·W09 포자·W11 벌떼·W18 비축고 채택.
- 보상 외형: 일반 경험치 점 / 특별 보상 도토리 확정. 특별 효과 미선택, X07~X10 보류.
- 아트: 신규 제작과 다람이 정체성 유지 확정. 세부 화풍·규격·시안 미선택.
