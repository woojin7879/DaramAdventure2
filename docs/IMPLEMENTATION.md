# 첫 플레이 초안 · v0.2

작성일: 2026-09-11. 실행 가능한 1년차 초안. 현재 작업은 로컬 플레이와 검토를 위한 결과이며 외부 배포는 하지 않았다.

## 이번 사용자 결정

- 활공 회피·대시·수동 스킬을 제거하고 이동과 자동 공격에 집중한다.
- 추가 결정이 필요하면 뱀서류의 일반적인 방향으로 진행한다.
- 기존 확정 사항: 매년 전투 성장 초기화, 무기 최대 6칸, 채택 무기 12종, 일반 경험치는 점, 특별 보상은 도토리, 이야기는 연차 클리어 후에만.

## 구현한 범위

- 1년차 귀환의 숲. 봄·여름·가을·겨울 각 300초, 종료 후 보스 등장.
- 빠른 체험은 계절당 75초. 정식 20분 모드를 대체하지 않는다. 난이도·드롭·무기 규칙은 같은 초안 규칙을 사용하며 짧은 성장 시간 때문에 정식 모드와 난이도가 같다는 뜻은 아니다.
- 12종 무기 레벨별 효과: 새총·꼬리·조약돌·덩굴·불씨·번개·눈송이·당구·부적·포자·벌떼·비축고.
- 패시브 6종, 각 최대 5레벨: 공격력 +10%, 공격 간격 −6%, 이동 +8%, 최대 체력 +20, 흡수 반경 +24, 범위 무기 +10%. 각 수치는 레벨당 증가량.
- 일반 경험치 점과 특별 도토리 3종. 자석은 필드 경험치 점 전체 회수, 회복은 체력 30, 힘은 12초간 피해 +30%. 특별 도토리는 경험치 8도 제공한다. 계절별로 다른 버프를 부여하는 안은 아직 적용하지 않았다.
- 일반 적 5종과 정예 변형, 겨울곰 보스의 돌진·원형 파동. 공격 예고를 표시한다.
- 피격 무적, 부적 차단, 광역 중복 타격 제한, 경험치 병합, 개체 상한.
- 계절 전환에도 위치·몬스터·경험치·전투 개체·타이머 유지. 화면 색과 새 적 구성, BGM만 점진적으로 전환하고 작은 계절명 표시를 추가한다.
- 정식 모드의 계절 시작 저장. 종료 후 마지막 경계부터 이어하기, 사망 시 해당 진행 종료. 보스전 중 종료하면 겨울 시작 저장으로 돌아온다. 저장 데이터 유효성 검증과 실패 안내.
- 승리·패배 결과, 기록, 클리어 후 1년차 엔딩. 빠른 체험도 엔딩을 미리 볼 수 있으나 정식 클리어 기록과 분리한다.
- 소리 토글, 원작 사계절 BGM과 합성 효과음. 화면 크기 대응, 기본 터치 방향키, 포커스 상실 자동 정지.

## 구현 선택

Vanilla JavaScript ES Modules + Canvas 2D + DOM 메뉴. 런타임 라이브러리 설치 없이 Node.js 기본 HTTP 서버와 복사 기반 정적 빌드를 사용한다. 기존 Vite 제안은 첫 초안의 간단한 실행을 위해 보류했다.

게임 규칙은 `src/game.js`, 수치와 성장표는 `src/data.js`, 렌더링은 `src/render.js`, 입력·메뉴·저장은 `src/main.js`로 분리했다. 60Hz 고정 갱신과 누적 갱신 제한을 사용한다. 적 탐색은 공간 격자로 줄이고 생성 개체를 제한한다.

지원 브라우저에서 현재 게임 상태를 읽는 선택적 WebMCP 도구를 등록한다. 미지원·등록 실패는 게임을 막지 않는다. 해당 API의 실제 브라우저 등록 검증은 아직 하지 않았다.

## 검증

- Node 기반 전투 규칙 테스트: 12종 성장표, 6칸 제한, 이동 속도 정규화, 일시정지, 연속 레벨업, 부적 충전, 경험치·연속 계절 전환, 보스 승리, 저장 복구, 지속 피해 중복 방지, 소환 상한, 한 해 시뮬레이션.
- JavaScript 구문 검사, 정적 빌드, 로컬 서버 HTTP 응답·에셋 경로 검사.
- 생성 아틀라스 1536×1024의 6×4 배치와 실제 투명 채널 확인. 바닥 이미지 시각 확인.
- 실제 브라우저에서 자동 클릭·스크린샷 검증은 수행하지 않았다. 사용자에게 로컬 플레이 미리보기를 제공했다.
- 시뮬레이션 통과는 실제 프레임 성능이나 난이도 검증을 의미하지 않는다. 조작감과 화력 곡선은 직접 플레이하면서 조정해야 한다.

## 남은 범위

- 2·3년차 맵·보스는 화면에서 ‘제작 예정’으로 표시하며 선택할 수 없다.
- 무기 진화와 전용 패시브 조합, 무기 도감은 미구현.
- 프레임별 캐릭터 실루엣·발 기준점과 배경 반복 이음새 추가 다듬기.
- 지형은 대부분 장식이며 통행을 막지 않는다. 후속 맵의 물길·환경 공격은 미구현.
- 전문적인 사운드 믹싱과 모바일 전용 조작감은 후속 작업.
- 초안 밸런스: 무기별 피해·범위, 경험치 곡선, 적 생성량과 보스 체력은 플레이 피드백으로 조정.

## v0.2 피드백 반영

제목을 다람이의 모험 2로 변경했다. 숲 오브젝트는 약 240개에서 72개로 줄이고 여백을 포함한 이미지 영역이 겹치지 않도록 배치한다. 얼음 고리·꼬리 휩쓸기·돌과 특별 도토리는 새 전용 아틀라스를 사용한다. 실행 중 계절 전환은 필드 상태를 유지하며, 저장에서 재개할 때는 플레이어 위치·성장을 복원하고 몬스터는 새로 생성한다.

## v0.3 전투 피드백 반영

- 덩굴 채찍: 진행하는 굴곡, 굵기가 줄어드는 덩굴, 끝의 타격 궤적. 번개: 세 겹의 방전 선, 분기, 타격 지점 불꽃. 전체 화면 섬광은 사용하지 않는다.
- 포자는 기존에도 적별 0.5초 공통 타격 간격이었다. 이제 겹친 포자 중 가장 높은 피해 하나를 적용하며, 생성 순서에 의존하지 않는다. 수명이 끝난 구름의 마지막 프레임 피해도 제거했다. 불 장판과 포자는 서로 다른 속성으로 각각 한 번씩 적용된다.
- 일반 적 체력 배율: 연차 진행도 p(0~1)에 대해 0.85 + 6.2 × p^1.55. 이전 겨울 약 2배에서 연차 말 7.05배로 상향. 이동 속도 최대 +35%, 접촉 피해 최대 +55%. 생성 간격은 0.85초에서 0.16초까지 연속적으로 감소한다. 보스 체력 7,920.
- 뱀은 굴곡을 그리며 추적한다. 박쥐는 고정 직선으로 횡단한 뒤 퇴장하며, 퇴장에는 처치·보상이 없다. 계절에 따라 5~11마리 떼가 추가로 횡단한다.
- 여우: 0.8초 예고 후 0.5초 빠른 돌진. 멧돼지: 1.1초 예고 후 0.85초 긴 돌진. 예고 때 정한 방향을 유지한다.
- 버섯: 거리를 유지하며 0.9초 예고 후 원거리 탄환 발사. 가을부터 3갈래 사격. 적 탄환 상한 90개. 이동으로 피할 수 있으며 전투·계절 전환 시 탄환 상태도 유지한다.
- 경험치 공식과 플레이어 레벨 상한은 변경하지 않았다. 종료 레벨 60은 가능한 성장 결과이며, 특정 종료 레벨에 강제로 맞추지 않는다. 새로운 난이도에 따른 레벨 분포는 후속 실제 플레이로 확인한다.
- 결과에 무기별 실제 피해(과잉 피해 제외), 보유 후 전투 시간 기준 DPS, 처치, 부적 방어, 받은 피해, 실제 회복, 이동 거리(월드 32단위=1m), 획득 경험치, 도토리별 획득, 적별 처치, 패시브와 전체 성장 선택 순서를 표시한다. 비축고 탄환은 새총과 별도, 불의 연소·장판도 불씨에 귀속한다.
- 계절 저장에 집계와 성장 기록을 보존한다. v0.2 저장은 이어한 시점 이후만 집계한다고 표시한다. 마지막 결과도 정식/빠른 체험 별도 로컬 저장한다.
- 연차 종료의 세 장면에 신규 삽화, 느린 화면 이동·전환, 빛 입자를 추가했다. 동작 줄이기 설정을 존중한다. 이야기는 기존처럼 연차 종료에만 나온다.

검증: 전투·표현 관련 Node 테스트 25개 통과. 동일 시드·동일 6무기 최대 강화/패시브 최대의 겨울 4분 비교에서는 정지 시 약 46초 후 사망, 원형 이동 시 4분 생존(남은 체력 약 17). 이 비교는 자동 회복 선택을 포함한 합성 시나리오이며 정식 20분 플레이의 난이도 확정을 의미하지 않는다. 실제 브라우저 자동 조작·스크린샷 테스트는 하지 않았다.

## v0.4 초반 개체수·비율 재검토

v0.3의 체력 성장·행동 차이는 유지하고 생성량을 낮췄다. 시작 무기가 약할 때 원거리 적이 쌓이는 문제를 개체수 예산으로 해결한다. 아래 수치가 v0.3 생성 간격·상한 설명을 대체한다.

| 정식 경과 | 생성 간격 | 전체 동시 상한 |
| --------- | --------: | -------------: |
| 시작      |     2.6초 |             12 |
| 1분       |     2.1초 |             20 |
| 3분       |     1.5초 |             36 |
| 5분       |     1.1초 |             60 |
| 10분      |    0.75초 |            100 |
| 15분      |    0.48초 |            140 |
| 20분      |    0.30초 |            180 |

구간 사이 수치를 연속 보간한다. 상한은 강제 생성 목표가 아니다. 살아 있는 적이 상한에 도달하면 추가 생성을 멈춘다. 보스 중에는 동시 40마리, 3초 간격이며 기존 개체를 지우지 않는다.

| 계절       |   뱀 | 여우 | 박쥐 | 버섯 | 멧돼지 | 버섯 동시 상한 |
| ---------- | ---: | ---: | ---: | ---: | -----: | -------------: |
| 봄 첫 90초 | 100% |    0 |    0 |    0 |      0 |              0 |
| 봄 이후    |  92% |    0 |    0 |   8% |      0 |  1, 3분 이후 2 |
| 여름       |  55% |  25% |  15% |   5% |      0 |              4 |
| 가을       |  35% |  30% |  15% |   8% |    12% |              6 |
| 겨울       |  28% |  27% |  18% |   7% |    20% |              8 |

비율은 일반 생성의 가중치다. 버섯이 상한이면 다른 종류에 재분배하며 정예와 횡단 박쥐 떼는 별도다. 첫 정예는 3분 후 여우, 이후 계절당 약 1~2회. 첫 박쥐 떼는 3분 30초 이후, 3~9마리, 45~33초 간격이며 전체 예산 안에서만 생성한다. 빠른 모드는 진행 곡선을 압축하지만 버섯은 최소 35초, 정예와 박쥐 떼는 최소 60초 이후에 등장한다.

버섯은 40초 후 사격 거점을 풀고 접근한다. 봄 사격 재사용 대기 6초, 이후 4.5초. 적 탄환 동시 상한 12/24/36/48. 보스 이외의 적이 화면 밖 먼 곳에서 35초 머무르면 보상 없이 퇴장하여 원거리 개체 누적을 막는다.

결정적 시드 비교: 겨울 6무기 완성 빌드 정지는 약 77초 후 사망, 같은 조건 원형 이동은 4분 생존·체력 약 137. 1분간 처치하지 않는 테스트에서도 최대 20마리·뱀만 생성. 합성 테스트이며 실제 플레이의 체감 난이도는 추가 피드백으로 조정한다.

제목 영역은 절대 좌표 대신 문서 흐름의 Grid로 배치한다. 제목/조작/관리자 버튼과 챕터 목록은 서로 다른 행이며 공간이 부족하면 내부 스크롤로 접근한다. 넓지만 낮은 화면은 제목과 여백을 줄이고, 좁은 화면은 한 열로 배치한다. 스토리 미리보기는 시작 화면에서만 진입하고 기록·진행을 변경하지 않는다. 마지막 장면/건너뛰기/ESC로 시작 화면에 복귀한다.

## v0.5 장비 표현·봄 밀도·시네마틱

- 조약돌 회전의 중심을 발 좌표에서 몸통(y−24)으로 옮겼다. `geometry.js`의 공통 함수를 렌더링과 충돌 모두 사용한다. 안쪽·바깥쪽 회전과 잔상도 같은 중심이다.
- 부적 충전 수를 나타내던 작은 점 대신 기존 숲 아틀라스의 나무껍질 부적을 머리·어깨 주변에 표시한다. 활성 부적은 선명하게 떠 있고, 소모된 부적은 희미하게 남으며 재충전 진행을 표시한다. 방어 시 부적과 빛 조각이 퍼진다.
- 첫 1분 생성 곡선은 유지한다. 2분은 0.95초/최대42마리, 3분 0.68초/64마리, 5분 0.6초/90마리, 10분 0.5초/116마리. 이후 겨울 곡선은 이전과 같다.
- 버섯은 정식 60초부터 12%, 최대2마리. 봄 3분부터 20%, 최대6마리. 여름 18%/10마리, 가을22%/14마리, 겨울20%/18마리. 각 계절 일반 생성 비율은 뱀/여우/박쥐/버섯/멧돼지 순서로 봄 후반80/0/0/20/0, 여름42/25/15/18/0, 가을25/26/15/22/12, 겨울20/24/16/20/20이다. 전체 예산과 탄환 상한, 오래된 버섯의 접근 행동을 유지한다. 빠른 모드의 첫 버섯 최소35초 보호도 유지한다.
- 스토리는 모달을 body로 이동시켜 게임 영역에 잘리지 않는 뷰포트 전체 시네마틱으로 표시한다. 원본 삽화를 자르지 않는 레터박스, 하단 자막, 장면 제목과 다음/닫기/음악 버튼을 제공한다. 브라우저 자체의 전체 화면 권한을 요구하지 않는다.
