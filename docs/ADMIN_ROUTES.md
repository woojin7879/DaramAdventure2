# 관리자 경로

일반 메인 메뉴에는 관리자 링크를 노출하지 않는다.

- `/admin.html`: 관리자 허브
- `/lab.html`: 무기 테스트
- `/boss.html`: 보스 체험
- `/?preview=0`: 프롤로그 미리보기
- `/?preview=1`, `/?preview=2`, `/?preview=3`: 연차별 엔딩 미리보기

미리보기는 기존 시네마틱 플레이어를 열며, 완료/닫기는 메인으로 돌아간다. 클리어·프롤로그 시청 기록을 쓰지 않는다. 배포 정적 파일에 포함되므로 경로 분리는 접근 인증을 의미하지 않는다.
