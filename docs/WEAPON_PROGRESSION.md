# 무기 슬롯과 레벨별 성장표

작성일: 2026-09-11. **동시 무기 최대 6칸은 확정.** 아래 최대 레벨과 효과는 구현 기준 초안으로 정하며, 수치는 플레이테스트 후 조정한다. 진화는 별도 후속 제안이다.

## 공통 규칙

- 시작 무기는 W01 도토리 새총 Lv.1을 제안한다. 시작 무기도 한 칸을 사용한다.
- 같은 무기는 중복 장착하지 않는다. 6칸이 차면 새 무기 후보는 제외하고 보유 무기 강화와 패시브만 제시한다. 첫 버전에는 무기 버리기·교체를 넣지 않는다.
- 새 무기 획득은 Lv.1, 이후 선택 한 번마다 1레벨 상승한다. 최대 레벨 무기는 일반 강화 후보에서 제외한다.
- 진화는 기존 무기를 같은 칸에서 교체하며 7번째 칸을 만들지 않는다. 패시브와 특별 도토리는 무기 칸을 사용하지 않는다. 패시브 슬롯 수는 별도 결정한다.
- 무기·강화·진화는 매년 초기화한다. 같은 해 계절 간에는 유지한다.
- 표는 **직전 레벨에서 바뀌는 값**을 적는다. 쓰지 않은 값은 유지한다. `→` 뒤는 최종값이며 반복 가산하지 않는다.
- 피해는 적 방어 적용 전 기본값. 거리 단위 u는 월드 좌표이며 렌더링 배율과 분리한다. 플레이어 충돌 반경 12u를 비교 기준으로 제안한다.
- 공격 주기는 발동 시작 간격. 탄환 수는 한 번 발동할 때의 수다. 사거리 밖에 표적이 없으면 공격을 보류하고 유효 표적이 생기면 발동한다.
- 투사체별로 같은 적을 한 번만 맞힌다. 지속 공격은 아래 개별 재타격 규칙을 따른다. 피해와 상태 효과 시간은 전투 정지 중 멈춘다.
- 일반 넉백은 표에 적힌 거리만큼 0.12초 동안 밀어내고 맵 장애물을 관통하지 않는다. 보스는 넉백 면역이며 감속은 최대 15%, 속박은 감속 15%로 대체한다.

## W13 · 불씨 도토리 — 최대 Lv.8

사거리 400u 내 가까운 적을 향해 탄속 280u/s로 발사한다. 첫 충돌에 직접 피해를 주고 해당 위치에 원형 불길을 남긴다. 도달 전 표적이 없어져도 최대 거리에서 불길을 만든다. 직접 피해와 불길 피해는 별개다.

같은 무기의 불길이 겹쳐도 적당 불길 피해는 0.5초마다 한 번만 적용한다. 최대 레벨 화상은 불길에 닿을 때 갱신되고, 불길을 떠난 뒤에도 지속한다. 화상끼리는 중첩되지 않는다.

| 레벨 | 효과 |
| --- | --- |
| 1 | 직접 피해 20, 주기 2.4초, 1발. 불길 반경 35u·지속 2초·0.5초마다 피해 3 |
| 2 | 직접 피해 20 → 28 |
| 3 | 불길 반경 35 → 48u |
| 4 | 불길 지속 2 → 3초, 틱 피해 3 → 5 |
| 5 | 주기 2.4 → 1.9초 |
| 6 | 1 → 2발. 가까운 서로 다른 표적을 우선 선택, 표적이 하나면 같은 적 조준 |
| 7 | 직접 피해 28 → 36, 불길 반경 48 → 60u |
| 8 | 불길 접촉 시 2초 화상 부여, 0.5초마다 피해 3. 화상 중 적이 죽으면 60u 내 가장 가까운 적 1명에게 화상 전파 |

전파 화상은 재전파하지 않는다. 화상 틱은 부여 0.5초 후부터 총 4회이며 시간 갱신으로 즉시 추가 틱을 만들지 않는다.

## W14 · 가지 번개 — 최대 Lv.8

사거리 400u 내 가장 가까운 적부터 시작한다. 한 발동에서 방문한 적은 다시 맞히지 않으며 유효한 다음 적이 없으면 종료한다. 연쇄는 즉시 처리한다. 표의 대상 수는 최초 표적을 포함한다.

| 레벨 | 효과 |
| --- | --- |
| 1 | 피해 22, 주기 2.8초, 최대 2명, 다음 대상 탐색 반경 100u |
| 2 | 최대 대상 2 → 3명 |
| 3 | 피해 22 → 30 |
| 4 | 탐색 반경 100 → 140u |
| 5 | 주기 2.8 → 2.2초 |
| 6 | 최대 대상 3 → 5명 |
| 7 | 피해 30 → 40 |
| 8 | 최대 대상 5 → 7명. 최초 표적에서 두 갈래로 분기하며 남은 6명을 각 갈래 최대 3명씩 탐색 |

분기는 두 갈래가 방문 기록을 공유한다. 한 갈래에 표적이 없으면 나머지 갈래가 남은 대상 한도를 사용한다. 단일 보스에게 7회 중복 낙뢰하지 않는다.

## W15 · 눈송이 고리 — 최대 Lv.6

발동 위치에서 고리가 0.6초 동안 바깥으로 퍼진다. 고리 두께 18u, 고리 하나당 적을 한 번 타격한다. 다람이가 이동해도 고리 중심은 발동 위치에 남는다.

| 레벨 | 효과 |
| --- | --- |
| 1 | 피해 10, 주기 3.2초, 최대 반경 110u, 감속 20%·1.5초 |
| 2 | 최대 반경 110 → 145u |
| 3 | 피해 10 → 16 |
| 4 | 감속 20 → 30%, 지속 1.5 → 2초 |
| 5 | 주기 3.2 → 2.6초 |
| 6 | 첫 고리 0.45초 뒤 같은 중심에서 두 번째 동일 고리. 같은 적도 고리마다 1회 피해 가능 |

감속은 합산하지 않고 강한 효과를 적용하며 동일 효과 재적중은 지속 시간을 갱신한다. 낮은 피해 대신 전방위 제어와 빠른 완성을 제공한다.

## W17 · 도토리 당구 — 최대 Lv.7

사거리 420u 내 가까운 적에게 탄속 360u/s로 발사한다. 맞은 뒤 180u 내 방문하지 않은 가장 가까운 적으로 방향을 바꾼다. 표의 명중 횟수는 최초 명중을 포함하며, 유효 표적이 없거나 탄환 수명 4초가 끝나면 종료한다.

| 레벨 | 효과 |
| --- | --- |
| 1 | 피해 14, 주기 2초, 1발, 탄환당 최대 3회 명중 |
| 2 | 피해 14 → 20 |
| 3 | 최대 명중 3 → 4회 |
| 4 | 주기 2 → 1.6초 |
| 5 | 1 → 2발, 서로 다른 초기 표적 우선. 표적이 하나면 같은 적 조준 |
| 6 | 피해 20 → 27, 최대 명중 4 → 6회 |
| 7 | 마지막 명중 위치에서 반경 48u·피해 18 폭발. 더 튕길 대상이 없어 종료할 때도 폭발 |

탄환별 방문 기록은 독립이다. 수명 종료 시에는 마지막 명중 위치에서 한 번만 폭발하고, 아무 적도 맞히지 않았다면 폭발하지 않는다. 마지막 표적은 직접 피해와 폭발 피해를 모두 받을 수 있다.

## W19 · 나무껍질 부적 — 최대 Lv.7

공격하지 않는 방어 무기로 **무기 슬롯 1칸**을 사용한다. 보호 횟수가 남아 있으면 피해를 받을 때 1회를 소비해 해당 피해와 부수 상태 이상·넉백을 막는다. 보스 공격에도 적용한다. 수치는 초기 밸런스 초안이다.

| 레벨 | 효과 |
| --- | --- |
| 1 | 보호 최대 1회, 20초마다 1회 재충전. 방어 성공 후 0.5초 무적 |
| 2 | 재충전 20 → 18초 |
| 3 | 보호 최대 1 → 2회 |
| 4 | 방어 성공 후 무적 0.5 → 0.7초 |
| 5 | 재충전 18 → 15초 |
| 6 | 보호 최대 2 → 3회 |
| 7 | 재충전 15 → 12초 |

- 최초 획득 시 보호 1회를 제공한다. 강화 시 현재 보호 횟수는 늘리지 않고 저장 상한과 시간만 변경한다.
- 보호가 최대치보다 적을 때만 단일 재충전 타이머가 진행된다. 완료하면 1회만 충전하며 아직 부족하면 다음 충전을 시작한다. 추가 피격은 진행 중 타이머를 초기화하지 않는다.
- 재충전 시간 강화 시 기존 충전 진행 비율을 유지한다. 일반 공격 주기 감소 패시브는 부적에 적용하지 않는다.
- 이미 무적이면 보호를 소비하지 않는다. 같은 시점의 여러 공격은 첫 방어 후 무적으로 처리해 보호가 한꺼번에 사라지지 않게 한다. 지속 피해도 실제 피해 틱 시점에 이 규칙을 따른다.
- 방어 성공 무적은 기존 무적과 시간을 합산하지 않고 더 늦게 끝나는 시점을 사용한다. 일반 피해를 막지 못한 경우에는 기존 피격 규칙을 따른다.
- 계절 전환·저장·재개에는 현재 보호 횟수와 충전 진행을 보존한다. 정지 중에는 충전도 멈추며 다음 연차에는 초기화한다.
- 다람이 발밑의 작은 껍질 표식 1~3개로 보호 잔량을 표시한다. 얼굴·꼬리를 가리는 상시 구체는 사용하지 않는다.

## W09 · 버섯 포자 — 최대 Lv.7

이동 거리를 누적해 지나온 위치에 포자 구름을 남긴다. 정지 중에는 생성하지 않는다. 구름은 지면에 고정되고 **같은 적은 모든 포자 구름을 합쳐 0.5초마다 한 번** 피해를 받는다. 직접 피해 없이 추격 경로를 만드는 무기다.

| 레벨 | 효과 |
| --- | --- |
| 1 | 이동 90u마다 구름 1개. 반경 30u, 지속 3초, 0.5초마다 피해 5, 동시 최대 6개 |
| 2 | 틱 피해 5 → 8 |
| 3 | 반경 30 → 42u |
| 4 | 생성 간격 90 → 70u, 동시 최대 6 → 8개 |
| 5 | 지속 3 → 4.5초 |
| 6 | 틱 피해 8 → 12 |
| 7 | 접촉 시 감속 20%·1초, 반경 42 → 50u, 동시 최대 8 → 10개 |

- 실제 입력 이동만 거리로 인정한다. 넉백·순간이동·계절 시작 위치 보정은 인정하지 않는다.
- 한 프레임에 기준 거리를 여러 번 넘으면 실제 이동 경로를 따라 간격대로 배치한다. 생성 시 누적 거리에서 사용 거리를 뺀다.
- 상한을 넘으면 가장 오래된 구름부터 제거한다. 포탑·불길과 개체 상한을 공유하지 않는다.
- 감속은 눈송이와 합산하지 않고 강한 효과만 적용한다. 접촉 중 남은 시간을 갱신하고, 보스 감속 상한 15%를 따른다.
- 일반 공격 주기 감소는 거리 기반 생성에 적용하지 않는다. 빠른 이동은 구름 생성 속도를 높이지만 최대 개수는 유지한다.
- 계절 전환에도 구름과 누적 이동 거리를 유지한다. 피해 판정은 투명도가 아니라 원형 영역을 기준으로 한다.

## W11 · 벌떼 친구 — 최대 Lv.8

벌은 다람이 주변에서 대기하다 자동 출격한다. 벌 자체에는 체력·피격·적 충돌 밀어내기 판정이 없다. 각 벌이 독립적으로 **대기 → 추적 → 타격 → 귀환 → 대기**를 반복한다.

| 레벨 | 효과 |
| --- | --- |
| 1 | 벌 1마리, 타격 피해 14, 탐색 반경 300u, 이동 속도 260u/s. 귀환 후 대기 1.8초, 출격당 최대 1회 타격 |
| 2 | 피해 14 → 20 |
| 3 | 벌 1 → 2마리 |
| 4 | 귀환 후 대기 1.8 → 1.4초, 이동 속도 260 → 320u/s |
| 5 | 벌 2 → 3마리 |
| 6 | 피해 20 → 28, 탐색 반경 300 → 380u |
| 7 | 벌 3 → 4마리 |
| 8 | 첫 타격 후 120u 내 다른 적 1명에게 추가 타격하고 귀환. 추가 타격도 동일 피해 |

- 벌마다 다른 표적을 우선 배정한다. 적이 하나뿐이면 여러 벌이 같은 적을 각각 타격할 수 있다.
- 출격당 동일 적은 한 번만 타격한다. Lv.8 추가 표적이 없으면 바로 귀환한다. 단일 보스에 출격당 두 번 타격하지 않는다.
- 적이 도중에 죽으면 현재 벌 위치 120u 내 다른 적을 찾고, 없으면 귀환한다. 출격 후 2초가 지나거나 다람이와 500u 이상 떨어져도 귀환한다.
- 귀환은 현재 다람이 위치를 추적한다. 귀환 시작 후 2초 안에 도착하지 못하면 플레이어 곁으로 복귀 처리한다. 귀환 중에는 피해를 주지 않는다.
- 신규 벌은 대기 상태로 생성하며 즉시 타격하지 않는다. 일반 공격 주기 감소는 귀환 후 대기에만 적용하고 최소 대기는 0.7초다.
- 계절 전환에도 벌의 위치·표적·공격·귀환 상태를 그대로 유지한다. 벌 수를 추가 탄환 효과로 복제하지 않는다.

## W18 · 겨울 비축고 — 최대 Lv.8

발밑에 작은 도토리 포탑을 자동 설치한다. 포탑은 지면에 남아 범위 내 가장 가까운 적을 향해 발사한다. 이동·길막·체력 판정이 없으며 설치 위치 주변을 돌며 싸울 때 효과적이다. 탄속 420u/s, 최대 이동 거리 현재 사거리+32u, 탄환당 한 명만 타격한다.

| 레벨 | 효과 |
| --- | --- |
| 1 | 설치 간격 8초, 포탑 최대 1개, 지속 12초. 포탑 사거리 360u, 사격 주기 1.2초, 1발, 피해 10 |
| 2 | 탄환 피해 10 → 15 |
| 3 | 포탑 최대 1 → 2개 |
| 4 | 포탑 지속 12 → 18초 |
| 5 | 포탑 사거리 360 → 460u, 사격 주기 1.2 → 0.9초 |
| 6 | 탄환 피해 15 → 21 |
| 7 | 포탑 최대 2 → 3개, 설치 간격 8 → 6초 |
| 8 | 포탑당 1 → 2발. 서로 다른 표적을 우선 조준하고, 표적이 하나면 동일 적에게 두 발 발사 |

- 최초 획득 시 포탑 1개를 설치하고 설치 타이머를 시작한다. 강화 시 기존 포탑에도 새 피해·사거리·사격 주기를 적용하지만 수명은 연장하지 않는다.
- 수명은 생성 시 확정한다. 최대 레벨에서 6초마다 설치하고 18초 유지하므로 정상 상태에서 최대 3개가 공존한다.
- 설치 상한을 넘으면 가장 오래된 포탑을 제거한다. 같은 위치 설치는 허용하고 장식 위치만 살짝 벌려 겹침을 줄인다.
- 표적이 없으면 사격을 보류한다. 표적이 진입하면 발사하고 사격 주기를 시작한다. 놓친 사격을 모아 한꺼번에 발사하지 않는다.
- 일반 공격 주기 감소는 포탑 사격에만 적용하며 최소 사격 주기는 0.45초다. 설치 간격에는 적용하지 않는다.
- 포탑은 플레이어와 멀어져도 사거리 내 시뮬레이션 중인 적을 공격한다. 계절 전환에도 기존 포탑과 수명·설치 타이머를 그대로 유지한다.
- 도토리 탄환은 보상 아이템과 구분되는 궤적을 쓰며, 경험치와 특별 도토리를 소비하지 않는다.

## 진화 — v1.1.0에서 구현

> 2026-09-15: 14종 진화와 보물상자를 v1.1.0에 구현했다. 조건은 **무기 최대 레벨 + 짝 패시브 최대 레벨**, 획득은 **정예 보물상자에서만**이며 레벨업 카드에는 나오지 않는다. 짝 패시브·효과 수치·상자 규칙·정예 강화는 [EVOLUTION_AND_CHESTS.md](EVOLUTION_AND_CHESTS.md)가 기준이다. 아래 표는 이름·효과의 원안 기록이다.

기본 최대 레벨만으로 각 무기를 완성형으로 사용할 수 있게 한다. 진화는 최대 레벨을 넘는 일반 강화가 아니라 형태를 교체하는 별도 보상이다. 아래는 방향 후보이며 이번 기본 성장표의 필수 구현에는 포함하지 않는다.

## 성장 속도와 검증 기준

6종을 모두 최대 강화하려면 구성에 따라 무기 선택 40~48회가 필요하다. 시작 새총 Lv.1을 무료로 받는 구성에서는 40~47회의 추가 선택이다. 패시브 선택도 필요하므로 경험치 곡선은 이 선택량을 고려해 설계한다. 모든 판에서 6종 완성을 보장하지 않되 20분 중반 이후 주력 무기의 완성 효과를 충분히 써볼 수 있어야 한다.

- 첫 최대 레벨 주력 무기는 여름 후반~가을 초반을 목표로 플레이테스트한다. 실제 획득 운과 강화 선택에 따라 달라진다.
- 6칸 상태의 신규 무기 차단, 무기별 최대 레벨 제외, 후보 부족 시 대체 회복을 확인한다.
- 원형·관통·연쇄 공격의 대상 수와 중복 피해 규칙을 각각 검증한다.
- 단일 보스, 밀집 적, 빠른 적, 포위 상황을 나눠 피해·생존 기여를 비교한다. 피해 합계만으로 방어 무기를 평가하지 않는다.
- 초당 공격 주기 감소는 최소 주기와 지속 효과의 개체 상한을 패시브 설계에서 정한다. 임시 버프 때문에 생성이 무한히 늘어나지 않게 한다.
- 6종 동시 최대 레벨, 화상 전파, 이중 고리, 경험치 다량 드롭을 합친 부하 상황을 확인한다.

- 부적: 동시 피격의 1회 소비, 지속 피해 틱, 보스 공격 방어, 최대 충전 정지, 계절 경계 충전 유지, 재시작 초기화를 확인한다.

- 포자·벌떼·포탑: 이동 거리 적산, 구름 중첩 피해 제한, 벌의 귀환과 표적 소멸, 포탑 수명·상한·계절 유지을 확인한다. 12종 중 6종을 고르는 조합에서 개별 생성 상한이 유지되어야 한다.


v0.6 설치 동작: 최대 설치 수에 도달하면 살아 있는 포탑을 강제로 교체하지 않는다. 수명이 끝나 자리가 생기면 새로 설치하며, 사격·소멸·재설치의 타이머는 각각 유지한다.
