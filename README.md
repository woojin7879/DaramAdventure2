# 다람이의 모험 2 · Darami Adventure 2

다람이의 모험에서 이어지는 JavaScript 생존 액션 게임. **브라우저·데스크톱 테스트 버전 v0.9**입니다.

맥·윈도우 실행 파일은 [GitHub Releases](https://github.com/woojin7879/DaramAdventure2/releases)에서 받습니다. 설치/빌드 안내는 [데스크톱 배포](docs/DESKTOP.md)를 참고하세요.

## 실행

Node.js 20 이상에서 외부 패키지 설치 없이 실행합니다.

```sh
npm run dev
```

브라우저에서 [게임 열기](http://localhost:4173). 정적 빌드는 `npm run build`, 전투 규칙 테스트는 `npm test`입니다. 빌드 결과는 `dist/`에 생성됩니다.

## 현재 플레이

- **스토리 모드**: 기존 1~3년차 캠페인. 정상 플레이 전체 클리어 시 **헬 모드** 해금.
- **헬 모드**: 10·20·30분에 연차 보스가 등장하고 이후 사망할 때까지 무한 생존. 성장 유지, 보스전에도 몹 생성, 별도 생존 기록. [규칙과 난이도](docs/HELL_MODE.md).

- WASD / 방향키 이동, 자동 공격. 활공·대시·수동 회피 없음.
- 1~3년차 선택. 각 연차는 사계절 각 5분, 총 20분 후 고유 보스와 최종전. 새 연차는 레벨·무기·패시브 초기화.
- 빠른 체험: 각 계절 75초, 총 5분 후 같은 보스. 정식 기록·진행 저장과 분리.
- 12종 무기 중 최대 6칸. 무기별 6~8레벨 강화, 레벨업 3개 중 선택.
- 패시브 6종, 경험치 점, 자석·회복·공격 강화 특별 도토리.
- 위치·전투가 이어지는 계절 전환, 계절 경계 저장, 일시정지, 사망·재시작, 연차 클리어 후 이야기.
- 새 다람이·스킬·종류별 도토리 에셋, 간격을 확보한 숲 오브젝트 적용.
- 박쥐 떼의 직선 횡단, 여우·멧돼지 예고 돌진, 버섯 원거리 사격, 뱀의 굴곡 추적. 후반 체력·속도·생성 압박 증가.
- 전체 화면 삽화·하단 자막·전용 합성 BGM을 곁들인 연차 엔딩. 결과에서 무기별 피해·DPS·처치, 성장 선택 기록 확인.
- 원작의 사계절 BGM을 반복 재생하고 계절 사이에 교차 전환. 소리 버튼으로 끄기 가능.

1년차 귀환의 숲(겨울곰의 잔영), 2년차 물길 너머의 숲(검은 물의 뱀), 3년차 오래된 뿌리의 숲(긴 겨울의 심장)을 플레이할 수 있습니다. 정식 클리어는 다음 연차를 해금합니다. 빠른 체험은 모든 연차를 바로 선택할 수 있으며 정식 해금에 반영되지 않습니다. 무기 진화와 4년차 이후는 미구현이며 밸런스는 초안입니다.

시작 화면의 **관리자 · 스토리 미리보기**에서 전투 없이 연차를 골라 엔딩의 세 자막 장면을 확인할 수 있습니다. 미리보기는 클리어·저장·통계에 반영되지 않습니다.

## 무기 테스트

시작 화면의 **관리자 · 무기 테스트** 또는 `/lab.html`에서 진입합니다. 무기 12종과 각 레벨, 최대 6칸 조합, 공격력·공격 간격·범위·속도 패시브를 즉시 변경합니다. 고정 표적 또는 실제 몬스터의 개수와 거리를 정하고 피해/DPS/명중을 확인할 수 있습니다. ‘피격 테스트’로 부적 차단을 확인합니다. 게임 저장과 클리어 기록을 읽거나 쓰지 않습니다.

무기 테스트에서도 연차를 바꾸고 각 연차 보스를 즉시 소환할 수 있습니다. 2·3년차 엔딩은 각 연차 전용 삽화 한 장에 세 자막 장면을 연결합니다.

3년차 최종 엔딩은 마법학교를 지키고 돌아온 부모님과의 재회부터 불씨·번개·눈송이의 비밀을 밝히는 14컷의 짧은 화자별 대화로 이어집니다. 마지막은 “너는 마법사란다, 다람아.”라는 반전으로 마무리합니다. [최종 엔딩 대본](docs/FINAL_ENDING_SCRIPT.md)과 호그와트로 연결되는 [디펜스 후속작 구상](docs/NEXT_GAME_CONCEPT.md)을 확인할 수 있습니다.

시네마틱은 약 70초 자동 재생하며 일시정지·이전·다음 조작을 지원합니다. 새 학교 방어전과 도토리 마법 시연 삽화를 포함해 6종의 배경으로 전환합니다.

관리자 [보스 체험](http://localhost:4173/boss.html): 연차별 즉시 소환, 체력 100/49/20%, 무적 전환, 6무기 Lv.5 추천 구성, 강화·패시브 수정, 실제 HP/피해 측정과 재시작. 저장·해금에 반영되지 않습니다.
