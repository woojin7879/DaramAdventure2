# 다람이의 모험 2 · Darami Adventure 2

다람이의 모험에서 이어지는 JavaScript 생존 액션 게임. **정식 버전 v1.0.1**입니다.

맥·윈도우 실행 파일은 [GitHub Releases](https://github.com/woojin7879/DaramAdventure2/releases)에서 받습니다. 설치/빌드 안내는 [데스크톱 배포](docs/DESKTOP.md)를 참고하세요.

## 패치노트

메인 화면 한켠에서 최신 버전과 요약을 확인하고 전체 패치노트를 열 수 있습니다. [v1.0.1 패치노트](CHANGELOG.md)에서 변경 내역을 확인할 수 있습니다.

다음 업데이트는 `src/release-notes.js`의 목록 맨 위에 추가하며 기존 내역을 유지합니다. 해당 파일이 게임 화면과 배포용 패치노트의 공통 원본입니다. `GAME_VERSION`, `package.json`, `package-lock.json`의 버전이 다르면 빌드가 실패합니다. 배포 승인 후 실제 공개 날짜를 기록합니다. 빌드 결과에도 `CHANGELOG.md`가 포함됩니다.

## 실행

Node.js 20 이상에서 외부 패키지 설치 없이 실행합니다.

```sh
npm run dev
```

브라우저에서 [게임 열기](http://localhost:4173). 정적 빌드는 `npm run build`, 전투 규칙 테스트는 `npm test`입니다. 빌드 결과는 `dist/`에 생성됩니다.

## 현재 플레이

- **스토리 모드**: 기존 1~3년차 캠페인. 정상 플레이 전체 클리어 시 **헬 모드** 해금.
- **헬 모드**: 10·20·30분에 연차 보스가 등장하고 이후 사망할 때까지 무한 생존. 30분 이후 적 체력이 복리로 올라 어떤 빌드도 결국 무너지는 기록 경쟁 모드. 가장 오래 버틴 한 판과 최근 10판을 기록. [규칙과 난이도](docs/HELL_MODE.md).
- **무기 진화·보물상자·도감**: 무기와 짝 패시브를 모두 최대 레벨로 올리고 정예의 보물상자를 열면 14종 진화. 발견한 진화는 시작 화면 도감에 영구 기록. [설계와 규칙](docs/EVOLUTION_AND_CHESTS.md).

- WASD / 방향키 이동, 자동 공격. 활공·대시·수동 회피 없음.
- 1~3년차 선택. 각 연차는 사계절 각 5분, 총 20분 후 고유 보스와 최종전. 새 연차는 레벨·무기·패시브 초기화.
- 접속 시 9.6초 사계절 질주 오프닝. 전용 달리기/멈춤 이미지, 다중 배경 이동, 계절 날씨와 검은 서리 연출. 건너뛰기/Esc/Enter 지원, 동작 줄이기에서는 1.5초 정적 타이틀. 소리는 기본 켜짐이며 인트로·게임·시네마틱의 변경 상태를 함께 저장합니다. 브라우저가 자동 재생을 제한하면 첫 입력 후 재생합니다.
- 14종 무기 중 최대 6칸. 무기별 6~8레벨 강화, 레벨업 3개 중 선택.
- 바람개비 씨앗: 발사 지점에서 나선 확산·감속, Lv.8에 씨앗 6개와 회전 방향 교대.
- 패시브 6종, 경험치 점, 자석·회복·공격 강화 특별 도토리.
- 위치·전투가 이어지는 계절 전환, 계절 경계 저장, 일시정지, 사망·재시작, 연차 클리어 후 이야기.
- 새 다람이·스킬·종류별 도토리 에셋, 간격을 확보한 숲 오브젝트 적용.
- 박쥐 떼의 직선 횡단, 여우·멧돼지 예고 돌진, 버섯 원거리 사격, 뱀의 굴곡 추적. 후반 체력·속도·생성 압박 증가.
- 전체 화면 삽화·하단 자막·전용 합성 BGM을 곁들인 연차 엔딩. 결과에서 무기별 피해·DPS·처치, 성장 선택 기록 확인.
- 원작의 사계절 BGM을 반복 재생하고 계절 사이에 교차 전환. 소리 버튼으로 끄기 가능.

1년차 귀환의 숲(겨울곰의 잔영), 2년차 물길 너머의 숲(검은 물의 뱀), 3년차 오래된 뿌리의 숲(긴 겨울의 심장)을 플레이할 수 있습니다. 정식 클리어는 다음 연차를 해금합니다. 일반 플레이의 빠른 체험은 제거했으며 스토리/헬 모드만 제공합니다. 4년차 이후는 미구현이며 밸런스는 초안입니다.

별도 관리자 허브에서 전투 없이 프롤로그와 연차별 시네마틱을 확인할 수 있습니다. 일반 메인 메뉴에는 관리자 링크를 표시하지 않습니다. 경로는 [관리자 경로](docs/ADMIN_ROUTES.md)에 정리했습니다. 미리보기는 클리어·저장·통계에 반영되지 않습니다.

## 무기 테스트

별도 관리자 허브 또는 `/lab.html`에서 진입합니다. 무기 14종과 각 레벨, 최대 6칸 조합, 공격력·공격 간격·범위·속도 패시브를 즉시 변경합니다. 고정 표적 또는 실제 몬스터의 개수와 거리를 정하고 피해/DPS/명중을 확인할 수 있습니다. ‘피격 테스트’로 부적 차단을 확인합니다. 게임 저장과 클리어 기록을 읽거나 쓰지 않습니다.

무기 테스트에서도 연차를 바꾸고 각 연차 보스를 즉시 소환할 수 있습니다. 2·3년차 엔딩은 각 연차 전용 삽화 한 장에 세 자막 장면을 연결합니다.

3년차 최종 엔딩은 마법학교를 지키고 돌아온 부모님과의 재회부터 불씨·번개·눈송이의 비밀을 밝히는 14컷의 짧은 화자별 대화로 이어집니다. 마지막은 “너는 마법사란다, 다람아.”라는 반전으로 마무리합니다. [최종 엔딩 대본](docs/FINAL_ENDING_SCRIPT.md)과 호그와트로 연결되는 [디펜스 후속작 구상](docs/NEXT_GAME_CONCEPT.md)을 확인할 수 있습니다.

시네마틱은 약 70초 자동 재생하며 일시정지·이전·다음 조작을 지원합니다. 새 학교 방어전과 도토리 마법 시연 삽화를 포함해 6종의 배경으로 전환합니다.

관리자 [보스 체험](http://localhost:4173/boss.html): 연차별 즉시 소환, 체력 100/49/20%, 무적 전환, 6무기 Lv.5 추천 구성, 강화·패시브 수정, 실제 HP/피해 측정과 재시작. 저장·해금에 반영되지 않습니다.
